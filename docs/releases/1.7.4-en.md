# XHYN V 1.7.4 English — test build

English-first launcher and trainer presentation for the supplied 1.7.4-named Android APK, with XHYN V branding and the purple V logo on a transparent background.

- English launcher pages, dialogs, accessibility labels, notifications, layout text and trainer display data.
- Removed the Chinese Android system-language gate; English text archives and fonts are selected without changing the phone's language.
- Preserved real file paths, native parser matching, command/model IDs, game configuration values and the other twelve native libraries.
- Existing touch/controller, graphics/driver, trainer, resource/mod and custom-radio interfaces are retained in English.
- New helper, patch, build and test code is available under a scoped MIT license, with translation data and verification records.

## Downloads

- `XHYN-V-1.7.4-English.apk` — signed English test APK.
- `XHYN-V-1.7.4-English-Public-Source.zip` — the complete public repository snapshot at this release tag. It excludes the original APK/engine, old proprietary source archive, game data and signing keys.
- `XHYN-V-1.7.4-English-verification.md` — detailed validation results and limits.
- `SHA256SUMS.txt` — checksums for the three files above.

The APK is named **XHYN V**, version `1.7.4-en`, app ID `com.xhynph.xhynv.reborn174`. It uses a new signing identity and a separate app ID; it does not update the original publisher's APK or the previous XHYN V package.

Android 11+, ARM64, a compatible Vulkan driver and the user's own compatible GTA V files with English text/fonts are required. Some catalog names use readable model identifiers rather than official localized names. The input filename said 1.7.4 but its manifest reported 1.7.1/code 84.

## Validation

**7,093 host checks** and **27 ARM64 instruction checks** passed. A fresh build using the public build driver also passed signature, DEX/resource, native preservation, PNG transparency/appearance, ZIP integrity and alignment audits.

**Android UI and gameplay remain untested on a device for this release.** The checks do not establish driver compatibility, performance, Story Mode completion or absence of all regressions. This release is marked as a prerelease for that reason.
