# XHYN V 1.7.4


- English launcher pages, dialogs, accessibility labels, notifications, layout text and trainer display data.
- No Chinese system-language setting is required; your phone stays in your preferred language.
- Kept real filenames, game settings and existing graphics options intact.
- Touch/controller controls, graphics options, mods, the trainer and custom radio remain available.
- Our modification sources and build tools are available in the repository.

Our release is **XHYN V**, version `1.7.4-en`, app ID `com.xhynph.xhynv.reborn174`. Earlier editions using different app IDs remain separate installations.

Android 11+, ARM64, a compatible Vulkan driver and the user's own compatible GTA V files with English text/fonts are required. Some catalog names use readable model identifiers rather than official localized names.

This is a development release. Compatibility and performance depend on the device, driver and game files.
