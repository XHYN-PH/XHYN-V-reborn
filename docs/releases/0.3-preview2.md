# XHYN V 0.3 Preview 2 — launcher startup fix

Preview 1 could close immediately without showing the launcher. Its rebuilt APK omitted 146 original artwork files required during application startup. Preview 2 restores those files, preserves their authentication and touch icons, and adds checks using the final signed APK's own resources.

Install **XHYN-V-0.3-Preview2.apk** over Preview 1; the app ID and release key are unchanged, and the version code is newer. There is no need to uninstall first. **XHYN V Bridge stays at 0.1.0**; an already installed copy does not need updating.

All 0.3 features remain: the 1.7.57 multiplayer base, LAN free roam, room chat, shared vehicles, street races, themes, XHYN graphics/DXVK controls and diagnostics. See the full [changelog and multiplayer guide](https://github.com/XHYN-PH/XHYN-V-reborn/blob/v0.3-preview2/README.md).

**Development preview:** startup and launcher checks pass in the host Android test environment. Physical-device gameplay, GPU behavior, multiplayer and Bridge VPN connections remain untested. Native heap/resource-cleanup and BC texture-copy problems remain open. This is custom free roam, not GTA Online; missions are not synchronized.

Game files are not included. Use your own compatible GTA V Legacy files and [buy GTA V from Rockstar](https://store.rockstargames.com/game/buy-gta-v).
