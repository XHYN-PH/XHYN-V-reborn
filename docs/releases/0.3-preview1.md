# XHYN V 0.3 Preview 1

This preview brings LAN multiplayer to XHYN V: free roam with up to 10 players, room chat, shared rides and street races. Everyone should use the same APK version and matching game/mod files. Missions are not synchronized, and this is not GTA Online.

The separate **XHYN V Bridge** companion helps remote players join the same virtual network. Its interface, notifications, widgets and network messages are in English. Local Wi-Fi/hotspot play does not require Bridge.

The game keeps its graphics controls, adjustable render scale, quality reset, single Vulkan driver menu and DXVK tuning/editor. The new base's conflicting memory controls are consolidated into the DXVK section. Theme, LAN and System → About remain separate pages.

Diagnostics preserve startup logs more reliably, explain more errors and help compare recordings made with the same settings. Normal startup avoids re-hashing bundled libraries.

This remains an experimental preview. Native heap/resource-cleanup crashes and some BC texture-copy paths are still under investigation; PanVK and Xclipse compatibility varies with the exact device and driver. Physical gameplay, live two-device multiplayer and sustained GPU/audio testing are still needed. See the detailed [implementation status](../../modifications/v0.3/STATUS.md).

Download the game APK to play. Install the Bridge APK only if you need the virtual LAN companion. Game files are not included. Use your own compatible GTA V Legacy files and [buy GTA V from Rockstar](https://store.rockstargames.com/game/buy-gta-v).
