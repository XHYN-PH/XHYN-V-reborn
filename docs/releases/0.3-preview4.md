# XHYN V 0.3 Preview 4

## What's new

- Vulkan Drivers and DXVK show what the game last loaded and what is selected for the next launch, including driver fallback.
- Driver ZIP imports show progress, can be cancelled, and keep your current driver selected. You can now view and clear shader caches individually.
- The touch layout editor has snap-to-grid and safe-area guides. Controls has a controller test for buttons, sticks, and dead zones.
- LAN room details show the host, local or virtual connection, and build compatibility information. You can view your enabled resource mods and measure outgoing traffic from the room.
- Large settings files can no longer stop launch when diagnostics tries to copy them. Startup also does less work on repeated package checks and optional reports.
- Supported phones have an optional sustained performance mode. Graphics startup errors now identify a rejected Direct3D feature level when the log records it.

## Install

Install **XHYN-V-0.3-preview4.apk** over Preview 3 Hotfix 1 to keep your settings. Use your own compatible GTA V Legacy files. [Buy GTA V](https://store.rockstargames.com/game/buy-gta-v)

This is a development preview. Gameplay, device performance, and live LAN still need testing on phones. LAN uses protocol 14. Use matching builds and gameplay mods in your group.
